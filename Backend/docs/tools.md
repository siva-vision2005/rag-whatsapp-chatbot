# AI Shopping Assistant Tools

---

## 1. Catalog Search

Purpose:
Search products from the product catalog.

Input:
- Brand
- Budget
- Processor
- RAM
- Storage
- GPU
- Purpose
- Category

Output:
- Matching products
- Product details
- Product links
- Product images

---

## 2. Product Comparison

Purpose:
Compare two or more products.

Input:
- Products

Output:
- Comparison table
- Pros & Cons
- Recommendation

---

## 3. Recommendation Engine

Purpose:
Recommend the best products.

Input:
- Budget
- Usage
- Brand
- Preferences

Output:
- Ranked products
- Reason for recommendation

---

## 4. Conversation Memory

Purpose:
Understand follow-up questions.

Input:
- Previous conversation
- Previous products

Output:
- Context
- Referenced products

---

## 5. General Knowledge

Purpose:
Answer questions that are not available in the catalog.

Input:
- User question

Output:
- AI generated answer

---

## 6. Response Generator

Purpose:
Generate a natural response.

Input:
- Planner output
- Tool results

Output:
- Final response for the user
